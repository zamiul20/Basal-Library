Zaming.zip contains a compressed python file that can be run on the command line to generate zaming graphs.

Prerequisites are:
1. python installed, version of at least 3.12
2. python package of pyarmor installed

Basal functions are included in the file, not externally needed.

Basal functions are included in the file, not externally needed.

To run: `python graph.py`, then follow the instructions

Input types to each prompt:

Base value: float

Base velocity: float

Base polarity: 
1. Regular - input 2
2. Negative - input 0
3. Double Negative - input 1

Base echo:
1. Regular - input 2
2. Positive - input 0
3. Negative - input 1

Base ripple (Note - Ripple will only take effect if Echo is not Regular): int

Range of values: int
Step of input values: float
offset: float
