# Singularitive operations

To perform one operation on all digits of a basal number, you can specify the operation, and on how many digits at a time.

You can also use this to perform an operation on two basal numbers of the same length, also digit-wise.

Put the operator (+, -) after the `য` E.g.
```
<3122T 1, 2, 5, 7, 3, 6, 98, 34 য+ 4 = <3122T 5, 6, 9, 11, 7, 10, 102, 38

<3122T 5, 6, 8, 1, 2, 3, 4, 7 য+ <3122T 1, 2, 5, 7, 3, 6, 98, 34 = <3122T 6, 8, 13, 8, 5, 9, 102, 41
The above example is regular addition of 2 numbers, but it uses the same method (it is digit-wise)

Below is singularitive multiplication
<3122T 5, 6, 8, 1, 2, 3, 4, 7 যx <3122T 1, 2, 5, 7, 3, 6, 98, 34 = <3122T 5, 12, 40, 7, 6, 18, 392, 238

Below is regular multiplication
<3122T 5 6 8 1 2 3 4 7 x <3122T 1 2 5 7 3 6 98 34 = <3122T 5 16 45 82 101 123 328 544 278 2888 388 831 1911 110 2672
```
