# Using the C++ files

The Basal.cpp file in /array_syntax/ is under development, and may not work as intended

Constructor - `Basal()` - makes an object with default parameters, entered parameters from collection to value or value to collection

Functions (using ebass as the object of class Basal), not all functions are in both files, read parameters of function to know what to input:
1. ebass.expor() : exponentiation of a collection to a power (mostly)
2. ebass.tobasten() : returns the value of a collection
3. ebass.notobasten() : returns the collection of a value
4. ebass.polaris() : returns the value of a depolarised collection
5. ebass.depolaris(): returns the depolarised variant of a collection
6. ebass.unechor() : returns the regular version of a echo-ed collection
7. ebass.echor() : returns the echo-ed version of a regular collection
8. ebass.logbas() : returns the logarithm of the first parameter from the second parameter
9. ebass.Convert() : sets the collection of a value of the object the function was called from in the variable `collection`
10. ebass.Deconvert() : sets the value of a collection of the object the function was called from in the variable `num_value`
