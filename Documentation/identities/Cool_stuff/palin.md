# Palindromes

Every value in existence ***could*** be a palindrome, just depending in what base it is to be represented in.

The only values that have palindrome representations are 1 (one) and 0 (zero), as 1 is x^0 for x being anything, and that 0 is just `0` in the 0th index.

Numbers of the exact same base can have the exact same value, but different digit collections: <2T 1, 1, 0 and 0.5, 1.5, 1

<31T 1 2 24 30 24 2 1 is a panindrome, but it is not a palindrome in denary (being <10T 9 6 7 8 4 3 3 4 4)

What if there was a value that is a palindrome in as many bases, to which there would be an infinite amount, as there could be an infinitesimal different of a base, making a completely different digit collection, which is also a palindrome.
